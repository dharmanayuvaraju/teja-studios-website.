## 🚀 Quick Deployment to GitHub & Vercel

### Step 1. Push to GitHub
1. Create a new repository on [GitHub](https://github.com/new) (e.g. `teja-studios-website`).
2. Run the following terminal commands:
```bash
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/teja-studios-website.git
git branch -M main
git push -u origin main
```

### Step 2. Deploy on Vercel
1. Open [Vercel](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..."** → **"Project"**.
3. Select your `teja-studios-website` repository and click **"Import"**.
4. Leave framework preset as **Other** (or Static HTML).
5. Click **"Deploy"**.
6. Your website is live worldwide with free SSL (e.g., `https://teja-studios.vercel.app`)!
